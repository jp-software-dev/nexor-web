This repository serves as the frontend architecture for the **NEXOR Industrial** platform. It is a modern, highly responsive Single Page Application (SPA) built with React and Vite that serves as the digital showcase for premium B2B bionic robotics, end-effectors, and advanced manufacturing solutions. The platform features an immersive **3D animated hero section**, dark-mode corporate UI/UX, and a secure serverless contact system optimized for high-ticket client acquisition.

## ✨ Features

* **Premium UI/UX Architecture & 3D Integration:** Clean, industrial dark-theme design system featuring polished micro-interactions, responsive CSS Grid layouts, and an interactive **3D bionic animation** component for maximum visual impact.
* **Serverless Contact Routing (WhatsApp):** Secure form processing that bypasses traditional backends, routing enterprise inquiries directly through the WhatsApp Business API for immediate technical engagement.
* **Smart Form Validation & Security:** Enterprise-grade form protection implementing strict regex validation (blocking non-numeric characters in phone inputs, enforcing domain formats), and reactive state management that disables submissions until data integrity is confirmed.
* **Dynamic Product Showcase:** Interactive UI frameworks displaying technical specifications, clinical/industrial context habitats, and multi-industry success cases without data duplication.
* **Responsive & Adaptive Layout:** Strict mobile-first styling utilizing Tailwind CSS utility classes to ensure a flawless, highly performant experience across all viewports, compressing complex B2B filters into clean horizontal scrolls on mobile devices.

## 🛠 Technologies Used

* **Core Framework:** React 18.x
* **Build Tool:** Vite
* **Languages:** TypeScript, HTML5
* **Design System:** Tailwind CSS, Lucide React (Iconography)
* **3D & Animations:** Integration of 3D animated components (e.g., Spline / Three.js).
* **Architecture:** Component-based structure, Custom React Hooks (`useParallax`), strict typed state management.

## 🚀 Installation & Setup

Follow these steps to deploy the development server locally. Ensure you have Node.js installed on your system.

1. Clone the repository:
```bash
git clone https://github.com/jp-software-dev/nexor-web.git

```

2. Navigate into the project directory:

```bash
cd nexor-web

```

3. Install the required dependencies:

```bash
npm install

```

4. Run the development server:

```bash
npm run dev
